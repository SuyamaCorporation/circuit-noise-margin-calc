## デジタル回路ノイズマージン計算機

CMOS/TTL/74LSのLogic Familyプリセット選択または手動電圧入力でNMH・NMLを計算し、電圧レベルダイアグラムをSVGで視覚化するデジタル回路設計教育ツール。

### 機能
- Logic Familyプリセット（CMOS 5V、CMOS 3.3V、TTL 5V、74LS）のワンクリック選択
- VOH/VOL/VIH/VIL手動入力によるカスタム計算
- NMH（VOH−VIH）・NML（VIL−VOL）の計算と良好/注意/危険判定
- SVGによる電圧レベルダイアグラム（HIGH帯/LOW帯/不定領域を色分け表示）

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
